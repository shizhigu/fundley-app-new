# ZenAsset Demo Script - Segmented Version (User-Facing)

> **Recording Strategy**: Split into 5 segments, edit together in post-production
> **Focus**: Show results and value, NOT technical implementation
> **Key Principle**: Never mention tools, APIs, or technical details - only show the final display_message

---

## Recording Plan

### Why Segment Recording?

**For beginners, segmented recording is MUCH easier**:

1. **Low pressure** - Make mistakes? Just re-record that 1-minute segment
2. **Better quality** - Can do multiple takes of each segment, pick the best
3. **Easier editing** - Add text overlays, zoom effects, music between segments
4. **Time flexible** - Record Segment 1 today, Segment 2 tomorrow if tired
5. **Natural pacing** - Can control exactly how long each part takes

### 5 Segments Structure

| Segment | Content | Duration | Difficulty |
|---------|---------|----------|------------|
| **Seg 1** | Hook + Setup | 45 sec | Easy |
| **Seg 2** | Comprehensive Analysis | 2 min | Medium |
| **Seg 3** | Narrative Insights | 1.5 min | Medium |
| **Seg 4** | Template Reuse | 1 min | Easy |
| **Seg 5** | Closing | 30 sec | Easy |

**Total Runtime**: ~5:45 after editing

- **Screen recording only** (full screen)

- **Mouse movements**: Slow and deliberate

2. Key operating margins

**[Pause 3 seconds - let Agent think]**

> "ZenAsset is intelligently figuring out where to find this data..."

**[Pause 3 seconds - wait for display_message to appear]**

> "...fetching financial statements from multiple sources..."

**[Pause - wait for Analysis Block to appear]**

**[Analysis Block titled "NVIDIA Financial Performance Analysis (Q1-Q4 2024)" appears on right panel]**

**[Hover over charts]**

> "...margin analysis across quarters..."

**[Scroll to peer comparison section]**

> "...and how NVIDIA compares to AMD and Intel."

### Show Transparency (KEY MOMENT)

**[Scroll back to chat panel on left]**

> "But here's what makes ZenAsset different: **transparency**."

**[Point to the display_message in chat]**

> "Every analysis shows you exactly what was calculated and where the data came from."

**[Scroll through the summary shown in chat]**

- ✅ "Fetching quarterly financial data for NVIDIA..."

## Editing Workflow (After Recording)

### Step 1: Review All Takes
- Watch all 5 segments from each take
- Mark the best version of each segment
- Note any mistakes that need fixing

### Step 2: Rough Cut
- Import best takes into video editor (DaVinci Resolve, Final Cut, Premiere)
- Place segments in order: Seg1 → Seg2 → Seg3 → Seg4 → Seg5
- Trim dead space at beginning/end of each segment
- Check total runtime (~5:30-6:00)

### Step 3: Speed Adjustments
- **Agent "thinking" time**: Speed up 2x, add animated "Analyzing..." text overlay
- **Your talking**: Normal speed (don't speed up)
- **Scrolling through results**: Normal or slightly slower (viewers need time to read)

### Step 4: Visual Enhancements
- **Zoom in** when showing key UI elements (Analysis Block title, charts, source links)
- **Highlight** important text with animated circles or arrows
- **Add text overlays**:
  - "Comprehensive Analysis" (during Segment 2)
  - "Narrative Intelligence" (during Segment 3)
  - "Template Reuse" (during Segment 4)

### Step 5: Audio & Music
- **Background music**: Subtle, upbeat (suggest: "Corporate Success" or similar royalty-free tracks)
- **Volume**: Music at 20-30% volume, narration at 100%
- **Audio cleanup**: Remove mouth clicks, normalize volume levels

### Step 6: Transitions
- **Between segments**: Simple crossfade (0.5 seconds)
- **Within segments**: Cut on action (when clicking, scrolling)
- **To final screen**: Fade to black, then logo appears

### Step 7: Final Polish
- Add lower-thirds with feature names (optional)
- Color grade for consistency
- Add captions/subtitles (helpful for non-native English speakers)
- End screen with social links + CTA (Last 5 seconds)

### Step 8: Export
- **Resolution**: 1080p (1920x1080)
- **Frame rate**: 30fps or 60fps
- **Format**: MP4 (H.264 codec)
- **Quality**: High bitrate (10-15 Mbps)

## Day-of-Recording Checklist

### 1 Day Before
- [ ] Test all queries in production (ensure stable results)
- [ ] Clear all existing chats and blocks (fresh start)
- [ ] Charge camera battery, clear SD card
- [ ] Rehearse script 3 times (don't memorize, internalize)

### 2 Hours Before
- [ ] Clean workspace (background visible in Segment 1 & 5)
- [ ] Set up lighting (ring light or window light on face)
- [ ] Test microphone (clear audio, no background noise)
- [ ] Close all other apps (browser only has ZenAsset tab)

### 30 Minutes Before
- [ ] Drink water (hydrate, clear throat)
- [ ] Test queries one more time (confirm Agent is working)
- [ ] Do a practice run-through (don't record yet, just rehearse)

### Recording Time
- [ ] Record Segment 1 (3 takes)
- [ ] **5 min break** (relax, breathe)
- [ ] Record Segment 2 (2 takes)
- [ ] **5 min break**
- [ ] Record Segment 3 (2 takes)
- [ ] **5 min break**
- [ ] Record Segment 4 (2 takes)
- [ ] **5 min break**
- [ ] Record Segment 5 (5 takes - this is your close, get it perfect)

### After Recording
- [ ] Watch all footage (make sure nothing is corrupted)
- [ ] Back up all video files (to cloud storage)
- [ ] Take a break! (editing tomorrow is fine)

## Key Differences from Technical Version

### ❌ NEVER Mention:
- API names (FMP, Polygon, MotherDuck)
- Technical terms (RAG, embeddings, Qdrant, E2B, Jupyter)
- Tool names (search_docs, call_api, run_python_code)
- "Agent", "LLM", "model" (just say "ZenAsset")

### ✅ ALWAYS Show:
- Final results (dashboards, charts, timelines)
- User benefit ("in 3 minutes", "verify sources", "reusable templates")
- Simplicity ("just type your question")
- Transparency ("see where data came from")

### The Golden Rule:
**If a user watching the demo would ask "what's that technical thing?", don't show it.**

Focus on **outcomes**, not **how it works under the hood**.

## Final Encouragement

**Don't stress about perfection!**

- Your first video won't be perfect — that's okay
- Segmented recording means you can redo any part that didn't work
- Editing can fix 90% of mistakes (awkward pauses, stumbles, etc.)
- Authenticity > polish (viewers can tell when you genuinely believe in your product)

**Most important**: Show the **value**, not the **complexity**. Users care about results, not technology.

You got this! 🎬
