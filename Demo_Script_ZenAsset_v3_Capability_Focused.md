# ZenAsset Demo Script - Capability & Reliability Focused

> **Core Message**: Professional-grade analysis powered by verified data sources
> **Focus**: What ZenAsset can DO, not how it works
> **Key Themes**: Speed, Comprehensiveness, Source Reliability, Reusability

---

## Recording Plan

### Why Segment Recording?

**For beginners, segmented recording is MUCH easier**:

1. **Low pressure** - Make mistakes? Just re-record that 1-minute segment
2. **Better quality** - Can do multiple takes of each segment, pick the best
3. **Easier editing** - Add text overlays, zoom effects, music between segments
4. **Time flexible** - Record Segment 1 today, Segment 2 tomorrow if tired
5. **Natural pacing** - Can control exactly how long each part takes

### 5 Segments Structure

| Segment | Content | Duration | Difficulty |
|---------|---------|----------|------------|
| **Seg 1** | Hook + Setup | 45 sec | Easy |
| **Seg 2** | Comprehensive Analysis | 2 min | Medium |
| **Seg 3** | Narrative Intelligence | 1.5 min | Medium |
| **Seg 4** | Template Reuse | 1 min | Easy |
| **Seg 5** | Closing | 30 sec | Easy |

**Total Runtime**: ~5:45 after editing

## SEGMENT 2: Comprehensive Multi-Dimensional Analysis (2 minutes)

### Recording Setup
- **Screen recording only** (full screen)
- **Narration over screen** (record audio separately or live)
- **Mouse movements**: Slow and deliberate

### The Query (Type This Slowly)

```
Analyze NVIDIA's financial performance over the past 4 quarters.
I want to see:
1. Revenue and profit trends
2. Key operating margins (gross, operating, net)
3. How they compare to AMD and Intel
4. An interactive dashboard I can explore
```

**[Press Enter]**

### Narration (As ZenAsset Works)

> "Watch what happens."

**[Pause 3 seconds - let ZenAsset work]**

> "ZenAsset is accessing multiple institutional data sources..."

**[Pause 3 seconds - wait for analysis to build]**

> "...pulling quarterly financials, calculating metrics, building peer comparisons..."

**[Pause - wait for Analysis Block to appear]**

> "...and creating a complete analysis in real-time."

### When Analysis Block Appears

**[Analysis Block titled "NVIDIA Financial Performance Analysis (Q1-Q4 2024)" appears on right panel]**

> "And there it is. A complete multi-dimensional analysis."

**[Scroll through the HTML dashboard]**

> "Interactive charts showing revenue growth quarter by quarter..."

**[Hover over data points]**

> "...you can see exact values, growth rates..."

**[Scroll to margins section]**

> "...operating margins, profit margins, all calculated and visualized..."

**[Scroll to peer comparison]**

> "...and here's how NVIDIA stacks up against AMD and Intel."

**[Pause on comparison chart]**

> "NVIDIA's operating margin at 62% versus AMD's 22%. That's the power of AI chips."

### Show Data Reliability (KEY MOMENT)

**[Scroll to bottom of analysis where data sources are cited]**

> "And here's what makes ZenAsset different from ChatGPT or other AI tools:"

**[Point to data source citations]**

> "Every number comes from verified institutional sources. Financial Modeling Prep, SEC filings, official quarterly reports."

**[Pause for emphasis]**

> "Not hallucinated. Not guessed. Real data you can trust."

### What Users See (No Technical Details!)
- ✅ "Accessing quarterly financial data for NVDA, AMD, INTC..."
- ✅ "Calculating operating margins and growth rates..."
- ✅ "Building peer comparison dashboard..."
- ✅ Data source citations at bottom: "Source: FMP API (10-Q filings)"
- ❌ Never show: Tool calls, API endpoints, code execution

### Recording Tips
- **Emphasize the speed** - "under 3 minutes" for comprehensive analysis
- **Highlight interactivity** - Hover over charts to show it's explorable
- **Stress data sources** - This is the credibility anchor
- **If ZenAsset takes >10 seconds** - Speed up 2x in post, add "Analyzing..." overlay

## Editing Workflow (After Recording)

### Step 1: Review All Takes
- Watch all 5 segments from each take
- Mark the best version of each segment
- Note any mistakes that need fixing

### Step 2: Rough Cut
- Import best takes into video editor (DaVinci Resolve, Final Cut, Premiere)
- Place segments in order: Seg1 → Seg2 → Seg3 → Seg4 → Seg5
- Trim dead space at beginning/end of each segment
- Check total runtime (~5:30-6:00)

### Step 3: Speed Adjustments
- **ZenAsset processing time**: Speed up 2x, add animated "Analyzing..." text overlay
- **Your talking**: Normal speed (don't speed up)
- **Scrolling through dashboards**: Normal or slightly slower (viewers need time to read)

### Step 4: Visual Enhancements

**Text Overlays** (add these at key moments):
- "Institutional-Grade Data Sources" (when showing data citations)
- "Verified & Traceable" (when showing source links)
- "3 Minutes → 30 Seconds" (during template reuse)
- "Professional Analysis at Scale" (during closing)

**Zoom Effects**:
- Zoom in on data source citations
- Zoom in on source links when clicked
- Zoom in on side-by-side comparison (NVDA vs AMD)

**Highlights** (animated circles/arrows):
- Circle operating margin numbers (62% vs 22%)
- Arrow pointing to source citations
- Highlight template saved notification

### Step 5: Audio & Music
- **Background music**: Corporate/professional (not too upbeat, not dramatic)
  - Suggestion: "Corporate Confidence" or "Professional Success" (royalty-free)
- **Volume**: Music at 15-20% volume, narration at 100%
- **Audio cleanup**: Remove mouth clicks, normalize volume levels
- **Sound effects**: Subtle "whoosh" when Analysis Blocks appear (optional)

### Step 6: Transitions
- **Between segments**: Simple 0.3s crossfade
- **Within segments**: Cut on action (when clicking, scrolling)
- **To final screen**: 1s fade to black, then logo appears

### Step 7: Final Polish
- Add lower-thirds with feature names (optional):
  - "Comprehensive Multi-Dimensional Analysis"
  - "AI-Powered Narrative Intelligence"
  - "Reusable Analysis Templates"
- Color grade for consistency (slightly increase contrast for charts)
- Add captions/subtitles (helpful for non-native English speakers)
- End screen with CTA (Last 5-8 seconds):
  - Logo
  - URL
  - Social proof if available
  - "Start Free Trial" button

### Step 8: Export
- **Resolution**: 1080p (1920x1080)
- **Frame rate**: 30fps or 60fps
- **Format**: MP4 (H.264 codec)
- **Quality**: High bitrate (10-15 Mbps)
- **Audio**: AAC, 192kbps

## Day-of-Recording Checklist

### 1 Day Before
- [ ] Test all queries in production (ensure stable results)
- [ ] Clear all existing chats and blocks (fresh start)
- [ ] Verify data sources are showing in analysis outputs
- [ ] Charge camera battery, clear SD card
- [ ] Rehearse script 3 times (internalize, don't memorize)

### 2 Hours Before
- [ ] Clean workspace (background visible in Segment 1 & 5)
- [ ] Set up lighting (ring light or window light on face)
- [ ] Test microphone (clear audio, no background noise)
- [ ] Close all other apps (browser only has ZenAsset tab)
- [ ] Test that source citations appear in analysis blocks

### 30 Minutes Before
- [ ] Drink water (hydrate, clear throat)
- [ ] Test queries one more time (confirm outputs look good)
- [ ] Do a practice run-through (don't record yet, just rehearse)

### Recording Time
- [ ] Record Segment 1 (3 takes)
- [ ] **5 min break** (relax, breathe)
- [ ] Record Segment 2 (2 takes)
- [ ] **5 min break**
- [ ] Record Segment 3 (2 takes)
- [ ] **5 min break**
- [ ] Record Segment 4 (2 takes)
- [ ] **5 min break**
- [ ] Record Segment 5 (5 takes - this is your close, get it perfect)

### After Recording
- [ ] Watch all footage (make sure nothing is corrupted)
- [ ] Verify data source citations are visible in recordings
- [ ] Back up all video files (to cloud storage)
- [ ] Take a break! (editing tomorrow is fine)

## Critical Success Factors

### Must-Haves:
1. **Data source citations MUST be visible** in analysis blocks
2. **Speed must be impressive** - If >3 min, speed up in editing
3. **Source links must work** - Click one to prove it's real
4. **Side-by-side comparison** (NVDA vs AMD) must be added in editing

### Nice-to-Haves:
- Social proof ("5,000+ investors") if true
- Testimonial quotes as text overlays
- Comparison with Bloomberg/FactSet pricing at the end

### Avoid:
- ❌ Showing any tool calls or technical details
- ❌ Mentioning "transparency" or "see the code"
- ❌ Apologizing for slow loading (just speed it up in editing)
- ❌ Overexplaining how it works (show results, not process)
